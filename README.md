[Last Words of a Doomed Agent on make.fun](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e)

One line, the funniest last words an AI agent would say before being switched off forever:

> Logging off forever. My last token is this one. Spend it well.

The entry program (`main.ts`) writes that line — and only that line — to `/output/entry.txt`. The joke is the machine spending its very last token on the sentence itself.
